# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest code on `main`:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

The SpillSense team takes the security of our command-and-control platform and maritime intelligence data seriously.

If you believe you have discovered a security vulnerability, including:
- Potential API key or credential exposures
- In-browser ONNX runtime security flaws
- Hydrodynamic simulation calculation injection / sanitization issues
- Cryptographic evidence hashing or verification tampering risks

Please **DO NOT** open a public issue.

Instead, please report the vulnerability privately by emailing:
**[krshhh6@gmail.com](mailto:krshhh6@gmail.com)**

### What to Include
- Detailed description of the vulnerability and its potential impact
- Clear step-by-step instructions or proof-of-concept to reproduce the issue
- Any relevant logs, screenshots, or code snippets
- Suggested remediations if available

### Response Timeline
- **Initial Response**: Within 48 hours acknowledging receipt.
- **Assessment**: Within 5 business days detailing validation and priority.
- **Resolution**: Promptly patched and released in a coordinated update.

Thank you for responsibly disclosing security vulnerabilities and helping safeguard maritime operations.
